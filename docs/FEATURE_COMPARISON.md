## 凡例

| マーク | 意味 |

| ○ | 対応（変更なし） |

## 開発者向け改善

### コード品質

| 項目 | オリジナル | Custom | 備考 |
|------|-----------|--------|------|
| コードアーキテクチャ | `LESmain.lua` 1,908 行の単一ファイル | 8 モジュールに分割（オーケストレーター ~132 行） | 保守性の大幅向上 |
| キーストローク処理 | if-else チェーン 25+ 段（O(n)） | ディスパッチテーブル（O(1)） | CPU 負荷 40-60% 削減 |
| シェル依存 | `/bin/zsh` 経由の `cp`, `mkdir`, `rm` 等 | 純 Lua I/O + `hs.fs` API | 6 関数を置換 |
| `string` ライブラリ上書きバグ | あり | 修正済み | 標準ライブラリ破壊を防止 |
| パラメータ名シャドウイング | あり | 修正済み | `string` → `path`, `str` |
| ファイルハンドル未クローズ | あり | 修正済み | `f:close()` 追加 |
| テーブルインデックス (0-indexed) | あり | 修正済み | Lua 標準の 1-indexed に統一 |
| `io.open` nil チェック | なし | 追加済み | |
